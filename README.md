# 🌊 Página Made in Abyss

Uma página web estática baseada na obra de fantasia sombria *Made in Abyss*, desenvolvida como um dos meus primeiros projetos durante o início dos meus estudos no curso de Desenvolvimento de Sistemas.

O projeto apresenta informações sobre a obra, sua história, personagens principais e as diferentes camadas do Abismo, utilizando uma interface temática construída com HTML e CSS.

---

## 📖 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento web, principalmente a construção e estilização de páginas utilizando **HTML5 e CSS3**.

A página é dividida em diferentes seções:

- 🏠 Sobre a obra
- 📜 História
- 👥 Personagens principais
- 🌌 O Abismo
- 🗺️ Camadas do Abismo
- 📚 Fontes e referências

A navegação utiliza links internos para facilitar o acesso às diferentes seções da página.

---

## 🛠️ Tecnologias

- HTML5
- CSS3

O projeto é totalmente estático e não utiliza JavaScript ou back-end.

---

## 🎨 Interface

A interface foi construída utilizando recursos básicos de CSS, incluindo:

- Flexbox
- CSS Grid
- Gradientes
- Imagens de fundo
- Navegação por seções
- Estilização de imagens
- Organização semântica da página

---

## 🌌 Conteúdo

A página apresenta uma introdução à obra, sua história e informações sobre alguns de seus personagens principais, além de uma seção dedicada ao Abismo e suas diferentes camadas.

## 🎯 Objetivo

O projeto foi desenvolvido durante o início dos meus estudos em desenvolvimento front-end, com o objetivo de colocar em prática os primeiros conhecimentos de HTML e CSS.

Além do objetivo técnico, o projeto também possui um significado pessoal: na época em que foi desenvolvido, eu estava acompanhando *Made in Abyss*, e a obra acabou servindo como inspiração para escolher o tema da página.

Hoje, este repositório também representa um registro de um dos primeiros passos da minha jornada como desenvolvedor.
